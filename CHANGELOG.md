# Changelog

## 0.1.0 - 2026-09-04

The first public Aelion Studio release.

- Build on the stable AelionSDK 2.0 public packages and Project v2 schema.
- Use an explicit magnetic storyline with freely positioned overlay tracks.
- Preview timeline moves before committing them as one undoable transaction.
- Keep linked audio aligned while storyline clips are repacked.
- Virtualize long timelines and reduce per-frame marker, transition and snapping work.
- Ship multi-track editing, local media persistence, browser preview and local WebCodecs export.
